# 쇼핑연습 (shopping-practice)

바닐라 JavaScript로 만든 쇼핑리스트 웹 앱입니다. 브라우저의 `localStorage`에 항목을 저장해 새로고침해도 목록이 유지됩니다.

## 기능

- 항목 추가 (입력 후 Enter 또는 "추가" 버튼)
- 항목 완료 표시 / 해제 (체크 또는 텍스트 클릭)
- 항목 삭제
- 완료된 항목 일괄 삭제
- 남은/전체 항목 개수 표시
- 라이트 · 다크 모드 자동 지원

## 사용법

`shopping-list.html` 파일을 브라우저에서 열면 바로 사용할 수 있습니다. 별도의 서버나 빌드 과정이 필요 없습니다.
